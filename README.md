# 🎮 小游戏合集 · 贪吃蛇 2048 消消乐 俄罗斯方块 数独

五个纯单文件的浏览器小游戏（无任何依赖），手机 / 电脑直接打开即玩。

## 🕹️ 包含游戏
- **🐍 贪吃蛇** — `snake.html`（28×28）
- **🔢 2048** — `2048.html`
- **🍬 消消乐** — `xiaoxiaole.html`
- **🧱 俄罗斯方块** — `tetris.html`（12×24）
- **🧩 数独** — `sudoku.html`（12×12，三档难度）
