# 🐍 贪吃蛇 · Snake

一个纯单文件的浏览器小游戏（无任何依赖），打开即玩。

## 🎮 玩法
- 吃掉红色苹果 **+10 分**
- 金色星星 **+30 分**（限时出现，带倒计时）
- 越吃越快，别撞墙也别咬到自己

## ⌨️ 操作
| 操作 | 按键 |
|---|---|
| 移动 | 方向键 / WASD |
| 暂停 | 空格 / P |
| 重开 | R |
| 手机 | 直接滑动屏幕 |
