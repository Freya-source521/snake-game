# 🎮 小游戏合集 · 贪吃蛇 2048 消消乐 俄罗斯方块 数独 扫雷 五子棋

七个纯单文件的浏览器小游戏（无任何依赖），手机 / 电脑直接打开即玩。**全部支持自动存档**（localStorage，关闭页面后回来可继续）。

## 🕹️ 包含游戏
- **🐍 贪吃蛇** — `snake.html`（28×28）
- **🔢 2048** — `2048.html`
- **🍬 消消乐** — `xiaoxiaole.html`
- **🧱 俄罗斯方块** — `tetris.html`（12×24）
- **🧩 数独** — `sudoku.html`（12×12，三档难度）
- **💣 扫雷** — `minesweeper.html`（三档难度）
- **⚫ 五子棋** — `gomoku.html`（双人/人机对战）
